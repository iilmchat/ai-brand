## 1. Общая информация

**Название бренда:** IIRuChating  
**Продукт:** AI Ru Chating — корпоративный мессенджер с локальным AI-ассистентом, построенный на материалах бренда

**Концепция логотипа:** чёрный шестиугольник с переплетающимся геометрическим узором внутри и текст "IIRuChating" внизу

## 2. Логотип

### 2.1 Описание
Логотип состоит из двух элементов:
- **Иконка** — чёрный шестиугольник (pointy-top) с переплетающимся геометрическим узором внутри. Эмблема выполнена как залитый контур (исходный файл `logo_new.svg`).
- **Текст** — "IIRuChating" в жирном начертании без засечек (Inter Bold), выровнен по центру под иконкой.

### 2.2 Варианты логотипа
| Вариант | Назначение | Файл |
|---------|------------|------|
| Исходный логотип (эмблема) | Мастер-файл, основа для всех вариантов | `logo_new.svg` |
| Полный логотип | Основной вариант для сайтов, презентаций, документов | `logo-full.svg` |
| Иконка | Для аватарок, панелей навигации, мобильных приложений | `logo-icon.svg` |
| Фавикон (светлая тема) | Вкладки браузера, закладки | `favicon.svg` (light) |
| Фавикон (тёмная тема) | Вкладки браузера в тёмном режиме | `favicon.svg` (dark) |
| Фавикон ICO | Устаревшие браузеры, Windows | `favicon.ico` |

### 2.3 Технические параметры иконки (из исходного SVG)
Эмблема — залитый контур (filled path) из файла `logo_new.svg`, не обводка.
- Исходный холст: 452 × 453 (эмблема занимает примерно x 40–416, y 11–440)
- Рабочий viewBox иконки: `8 6 440 440`, отрисовка 64 × 64 px
- Заливка: `currentColor`, без обводки (`stroke="none"`)
- Цвет: чёрный (`#000000`) на светлом фоне

### 2.4 Технические параметры полного логотипа
- Холст: 240 × 96 px, `viewBox="0 0 240 96"`
- Эмблема 64 × 64 px сверху, по центру (x 88, y 2)
- Текст: `IIRuChating`, Inter Bold, выравнивание по центру, под эмблемой (baseline y 90)
- Текст переведён в кривые, поэтому логотип отрисуется одинаково без установленных шрифтов

| Назначение | Цвет | HEX | Применение |

| Фон (основной) | Белый | `#FFFFFF` | Фон логотипа, интерфейс |
| Акцент (премиальный градиент) | Электрический фиолет | `#8B5CF6` | Вариант А (градиентная заливка) |
| Акцент (цветной) | Неоновый синий | `#0EA5E9` | Вариант В (цветные акценты) |

**Правило:** логотип допускается только в чёрном на светлом и белом на тёмном. Не использовать полупрозрачность, градиенты в базовой версии, радужные заливки.

### 3.1 CSS коды цветов

Для быстрого подключения в веб-интерфейсе используйте CSS-переменные:

```css
:root {
  /* Основные цвета бренда IIRuChating */
  --iiru-brand-black: #000000;
  --iiru-brand-white: #FFFFFF;
  --iiru-accent-violet: #8B5CF6;
  --iiru-accent-blue: #0EA5E9;
  --iiru-accent-emerald: #10B981;
  --iiru-bg-dark: #1E293B;
  --iiru-text-on-dark: #FFFFFF;
}

/* Тёмная тема */
@media (prefers-color-scheme: dark) {
  :root {
    --iiru-surface: #0F172A;
  }
}
```

| Цвет | HEX | RGB | HSL | CSS переменная | Применение |
|------|-----|-----|-----|----------------|------------|
| Чёрный (основной) | `#000000` | `rgb(0, 0, 0)` | `hsl(0, 0%, 0%)` | `--iiru-brand-black` | Логотип на светлом фоне, текст |
| Белый (фон) | `#FFFFFF` | `rgb(255, 255, 255)` | `hsl(0, 0%, 100%)` | `--iiru-brand-white` | Фон, инверсия логотипа |
| Электрический фиолет | `#8B5CF6` | `rgb(139, 92, 246)` | `hsl(270, 89%, 66%)` | `--iiru-accent-violet` | Вариант А, градиентная заливка |
| Неоновый синий | `#0EA5E9` | `rgb(14, 165, 233)` | `hsl(199, 92%, 53%)` | `--iiru-accent-blue` | Вариант В, цветные акценты |
| Изумрудный | `#10B981` | `rgb(16, 185, 129)` | `hsl(160, 84%, 41%)` | `--iiru-accent-emerald` | Вариант В, центральный акцент |
| Тёмно-синий | `#1E293B` | `rgb(30, 41, 59)` | `hsl(212, 33%, 17%)` | `--iiru-bg-dark` | Градиент, тёмные фоны |

**Правило:** не используйте полупрозрачность, градиенты в базовой версии логотипа и радужные заливки. Акцентные цвета применяются только по вариантам А и В (раздел 5).

### 3.2 Material 3 цветовая схема (для интерфейсов)

Для веб- и мобильных интерфейсов палитра построена по алгоритму Material 3 (Material Color Utilities, схема **Fidelity**):
- **Primary** — `#8B5CF6` (электрический фиолет, сохраняет тон бренда).
- **Tertiary** — `#0EA5E9` (неоновый синий). Построен из своего seed-цвета, а не из стандартного M3-сдвига, чтобы акцент остался брендовым.
- **Secondary** — производный от primary, **neutral** и **neutral-variant** — серо-фиолетовые, **error** — стандартный M3.

Готовые значения:
- `theme-m3.css` — роли `--md-sys-color-*` для светлой и тёмной темы (`[data-theme]` и `prefers-color-scheme`) и тональные палитры `--md-ref-palette-*`.
- `color-palette-m3.svg` — визуальная шпаргалка: тональные палитры tone 0–100 и роли обеих схем.

Ключевые роли:

| Роль | Светлая | Тёмная |
|------|---------|--------|
| primary | `#6B38D4` | `#D0BCFF` |
| onPrimary | `#FFFFFF` | `#3C0091` |
| primaryContainer | `#8455EF` | `#A078FF` |
| tertiary | `#006591` | `#89CEFF` |
| surface | `#FEF7FF` | `#15121B` |
| onSurface | `#1D1A23` | `#E7E0ED` |

**Правило:** в компонентах используйте роли (`var(--md-sys-color-primary)`), а не сырые HEX. Тогда светлая и тёмная темы переключаются сами. Все пары «фон — текст» проверены по WCAG AA (контраст не ниже 4.5:1).

## 4. Типографика

Текст "IIRuChating" набирается жирным геометрическим sans-serif. Рекомендуемые шрифты:

| Шрифт | Начертание | Почему подходит | Источник |
|-------|------------|-----------------|----------|
| **Inter** | Bold (700) / SemiBold (600) | Идеальная читаемость на малых размерах, сбалансированные пропорции, открытые формы букв `u`, `a`, `t` | Google Fonts (бесплатно) |
| **Manrope** | Bold (700) | Более техно-характер, хорошо держит жирное начертание, подчёркивает цифровую природу продукта | Google Fonts (бесплатно) |
| **Montserrat** | ExtraBold / Bold (700–800) | Выраженные заглавные буквы, солидный и стартаповый вид, особенно хорошо смотрятся `II` в начале | Google Fonts (бесплатно) |

**Рекомендация:** использовать **Inter Bold** как основной шрифт логотипа. Для заголовков на сайте можно добавить второй шрифт (например, с засечками для длинных текстов), но внутри самого логотипа сохранять монотипографику.

**Параметры текста:**
- Начертание: 700 (Bold)
- Выравнивание: по центру (text-anchor: middle)
- Отступ от иконки: 8–12 px
- Цвет: `#000000` (или `#FFFFFF` на тёмном фоне)

## 5. Варианты развития дизайна

Все варианты построены на исходной эмблеме из `logo_new.svg`.

### Вариант А: Градиентная заливка (премиальный, цифровой)
- Вся эмблема заливается линейным градиентом: от тёмно-синего (`#1E293B`) до электрического фиолета (`#8B5CF6`).
- Текст остаётся чёрным.
- Файлы: `logo-variant-A-icon.svg`, `logo-variant-A-full.svg`.
- Применение: тёмные фоны приложения, welcome-страницы, баннеры.

### Вариант Б: Разрыв линий (динамика, цифровой сигнал)
- Чёрная эмблема с четырьмя белыми разрывами на диагональных линиях узора. Контур шестиугольника не прерывается.
- Разрывы по ширине около 1.5 px в иконке 64 × 64 px.
- Файлы: `logo-variant-B-icon.svg`, `logo-variant-B-full.svg`.
- Применение: анимация при наведении (hover), заставки, иконки навигации.

### Вариант В: Цветная акцентная версия (узнаваемость)
- Базовая ЧБ-версия остаётся главной.
- Две противоположные диагонали узора окрашиваются в неоновый синий `#0EA5E9`, центральный ромб — в изумрудный `#10B981`.
- Файлы: `logo-variant-C-icon.svg`, `logo-variant-C-full.svg`.
- Применение: аватарки профилей, стикеры, мерч, соцсети.

## 6. Правила применения

### 6.1 Чистое пространство (Clear Zone)
Вокруг логотипа оставляйте свободное место не менее высоты одной буквы текста. Логотип не должен прилипать к другим элементам интерфейса.

Для логотипа 240 × 96 px это **17.5 px** со всех сторон (высота заглавной буквы Inter Bold при кегле 24 px). Схема с рамкой — в файле `clear-zone.svg`.

### 6.2 Минимальные размеры
| Носитель | Минимальный размер |
|----------|-------------------|
| Иконка | 16 × 16 px |
| Полный логотип | 120 px по ширине |
| Фавикон | 16 × 16 px |

### 6.3 Фоны и контраст
- Чёрная версия — только на белом или светло-сером фоне.
- Белая версия — только на чёрном или тёмном фоне.
- Не размещать на пёстрых, градиентных или фотографических фонах без затемнения.

### 6.4 Допустимые изменения
- Изменение размера (пропорционально).
- Инверсия цвета (чёрный ↔ белый) при смене темы интерфейса.
- Анимация внутреннего узора (последовательное зажигание линий, медленное вращение 360° за 4–6 с).

### 6.5 Запрещено
- Наклонять, растягивать неравномерно, поворачивать под углом.
- Менять толщину контура или отдельных элементов эмблемы.
- Добавлять тени, обводки, свечение к базовому логотипу.
- Использовать логотип менее 16 × 16 px (текст станет неразборчивым).
- Размещать на цветном фоне без обеспечения контраста.

### 6.6 Антипримеры использования

Ниже перечислены наиболее распространённые ошибки при использовании логотипа. Подробная визуальная шпаргалка — в файле `anti-examples.svg` в рабочей папке брендбука.

| # | Антипример | Почему нельзя |
|---|------------|---------------|
| 1 | Наклон логотипа под углом | Нарушается геометрия шестиугольника и баланс элементов |
| 2 | Неравномерное растяжение (только по одной оси) | Искажаются пропорции эмблемы и её узор |
| 3 | Тень, обводка или свечение вокруг логотипа | Базовый логотип должен оставаться плоским, без эффектов |
| 4 | Утолщение или дополнительная обводка контура эмблемы | Нарушается исходный контур логотипа |
| 5 | Логотип менее 16 × 16 px | Текст "IIRuChating" становится неразборчивым |
| 6 | Цветная заливка, градиент или радуга в базовой версии | Нарушается правило строгой ЧБ-версии логотипа |
| 7 | Размещение на пёстром, градиентном или фотографическом фоне без затемнения | Отсутствует контраст, логотип теряется на фоне |
| 8 | Логотип «прилипает» к краям других элементов интерфейса | Нарушается правило чистого пространства (clear zone) |

**Правило:** если нужно выделить логотип, используйте акцентный вариант (раздел 5), а не искажения и эффекты.

## 10. Гайд для разработчиков (быстрое подключение)

### 10.1 Подключение логотипа в HTML

```html
<!-- Полный логотип (основной вариант) -->
<img src="images/logo-full.svg" alt="IIRuChating" width="240" height="96" />

<!-- Иконка (аватарки, навигация, мобильные приложения) -->
<img src="images/logo-icon.svg" alt="IIRuChating" width="64" height="64" />
```

Логотип залит `currentColor`, поэтому цвет задаётся свойством `color`, но **только при встраивании SVG прямо в HTML** (inline). Через `<img>` CSS-цвет не меняет логотип. Для тёмной темы при `<img>` используйте `filter: invert(1)` или подключите отдельный файл:

```css
.logo-inline { color: var(--iiru-brand-black); }      /* inline SVG, светлая тема */
.logo-inline-dark { color: var(--iiru-brand-white); }  /* inline SVG, тёмная тема */
```

### 10.2 Фавикон с поддержкой тёмной темы

```html
<link rel="icon" type="image/svg+xml" href="images/favicon.svg" />
<link rel="icon" href="images/favicon.ico" sizes="32x32" />
```

`favicon.svg` сам переключает цвет через `prefers-color-scheme`, поэтому отдельный `media` для него не нужен.

### 10.3 React-компонент

```jsx
import logoIcon from '../images/logo-icon.svg';

export function Logo({ size = 64, theme = 'light' }) {
  return (
    <img
      src={logoIcon}
      alt="IIRuChating"
      width={size}
      height={size}
      style={{ filter: theme === 'dark' ? 'invert(1)' : 'none' }}
    />
  );
}
```

### 10.4 Минимальные размеры и clear zone

| Элемент | Минимальный размер |
|---------|-------------------|
| Иконка | 16 × 16 px |
| Полный логотип | 120 px по ширине |
| Фавикон | 16 × 16 px |

Свободное пространство вокруг логотипа — не менее высоты одной буквы текста. Логотип не должен «прилипать» к другим элементам интерфейса.
