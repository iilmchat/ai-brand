# Исходные файлы бренда IIRuChating

## Редактируемые исходники

Редактируемые исходники макета логотипа хранятся в форматах:

- `.fig` — Figma (основной редактор)
- `.ai` — Adobe Illustrator (альтернатива)

В этой папке исходники **не включены** в публичный брендкит. Чтобы получить исходники:

1. Обратитесь к владельцу бренда IIRuChating.
2. Укажите цель использования (редизайн, адаптация под носитель, мерч и т.д.).
3. Получите файлы по согласованным каналам передачи.

## Что можно править самостоятельно

Из файлов текущего брендкита можно редактировать без исходников:

- `logo_new.svg` — мастер-эмблема (исходная геометрия).
- `logo-full.svg`, `logo-icon.svg`, `favicon.svg` — векторные файлы, правятся в любом редакторе SVG (Inkscape, Illustrator, Figma).
- `logo-variant-A-*.svg`, `logo-variant-B-*.svg`, `logo-variant-C-*.svg` — варианты А, Б и В. Построены из `logo_new.svg` маской и клипами, поэтому при правке эмблемы их нужно пересобрать.
- `color-palette.svg`, `anti-examples.svg`, `clear-zone.svg` — визуальные шпаргалки.
- `BRAND_BOOK_IIRuChating.md` — текст брендбука.
- `fonts.css`, `FONTS.md` — подключение шрифтов.

## Структура для дизайнеров

Эмблема в `logo_new.svg` — один залитый контур (без разделения на слои), поэтому в исходниках `.fig` / `.ai` ожидайте:

- `Иконка` — эмблема-шестиугольник с узором;
- `Текст` — `IIRuChating`, шрифт Inter Bold (в кривых).
